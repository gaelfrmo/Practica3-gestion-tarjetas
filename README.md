# Sistema de Gestión de Tarjetas

Sistema en consola (Java) para administrar tarjetas de **Débito** y **Crédito** aplicando POO.

##  Contents:

- **Crear Tarjeta:** Registra crédito o débito con NIP (4 dígitos), banco y límites personalizados.
- **Tarjetero:** Busca tarjetas registradas por sus últimos 4 dígitos.
- **Acciones Generales:** Consultar saldo, bloquear, desbloquear y reportar robo.
- **Operaciones por Tipo:**
  - **Débito:** Retiros, depósitos, transferencias y compras.
  - **Crédito:** Pagos de saldo, compras y extensión de límite.
